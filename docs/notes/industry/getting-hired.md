## What each stage is actually testing

| Stage | What it checks | How to pass |
|---|---|---|
| Resume filter | keywords, degree, a link that works | one page, real projects, a live URL |
| Phone screen | can you talk about your work | explain your project in two minutes |
| Technical round | data structures, algorithms | practice. There is no other route |
| System design | can you shape a solution | usually skipped for freshers |
| Culture round | will you be pleasant to work with | ask real questions |

---

## Your project is the whole first half

Most graduates apply with a tutorial to-do app. You have something better, and it is worth being
deliberate about saying so.

<ol class="steps">
  <li><strong>Deploy it.</strong> A URL a recruiter can click beats any description of it.</li>
  <li><strong>Write the README as if a stranger is reading.</strong> What it does, how to run it, what you would do next.</li>
  <li><strong>Be able to explain any file.</strong> "Why is the rule in <code>api/</code> and not <code>database/</code>?" is a question you can answer.</li>
  <li><strong>Have three decisions ready</strong>, each with the reason.</li>
</ol>

!!! success "The line that separates you from other freshers"
    Not "I built a full stack CRUD app". Everybody says that.

    **"I migrated it from SQLite to Postgres and only two files changed, because the database
    layer was isolated."** That is a sentence about design, and juniors do not usually have one.

---

## Two things people skip

**Practise data structures and algorithms.** It is a filter, it is not going away, and it is
learnable. An hour a day for three months clears most fresher interviews.

**Apply to more places than feels reasonable.** Look at the funnel again. Ten applications is
not a sample.

---

## Rejection, briefly

You will be rejected far more than accepted, and mostly you will not learn why. Companies rarely
give reasons.

The only useful response is to ask, once, politely, whether there is any feedback, and then keep
going. **The funnel is a numbers game with a skill component**, and both halves need work at the
same time.
